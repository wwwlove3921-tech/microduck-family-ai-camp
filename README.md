# Microduck AI 机器人训练营

家庭共学机器人训练营宣传页面。静态 HTML，适配手机与桌面浏览器。

- 网站：https://wwwlove3921-tech.github.io/microduck-family-ai-camp/
- 入口：`index.html`
- 发布：GitHub Pages 从 `main` 分支根目录发布。

## 内容

周末家庭共学、一对一带领、建模与 3D 打印、视频标注和 AI 训练体验、机器人组装与调试。课程暂定价为 8999 元/家庭，包含 1 台机器人的课程制作材料。

## 视频

页面包含 NVIDIA 官方 Microduck 现场视频入口，以及 Microduck 官方产品演示。视频需要联网播放；现场视频的 YouTube 源可能受访问网络影响，页面提供切换到官方产品演示的入口。产品视频用于展示参考，课程成品配置与功能以报名约定为准。

## 更新

修改 `index.html` 并提交到 `main` 后，GitHub Pages 会自动重新发布。
